# 3D Models Directory

You can place your high-fidelity GLTF / GLB models here:
- `basic_pc.glb` (Entry level gaming PC)
- `pro_pc.glb` (High performance gaming PC)
- `ultra_pc.glb` (Extreme flagship gaming PC)

The NEXUS PC RENTAL 3D viewer supports automatic GLTF loading with fallback to the high-detail procedural PBR hardware components.
